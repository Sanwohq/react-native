# @sanwohq/react-native

React Native SDK for [Sanwo](https://sanwohq.com) — one interface for every payment provider.

> **Full documentation at [docs.sanwo.dev](https://docs.sanwo.dev/sdks/react-native/)** — guides, examples, and API reference for every SDK and provider.

## Install

```bash
npm install @sanwohq/react-native @sanwohq/paystack
```
